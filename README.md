# 多多打卡

面向 6 岁孩子的原生 iPhone 打卡 App。SwiftUI 太空探索界面，SwiftData 本地记录，无账号、无广告、无云同步。最低 iOS 17。

## 打开与运行

1. 使用 Xcode 打开 `DodoCheckIn.xcodeproj`，选择 `DodoCheckIn` Scheme。
2. 选择 iPhone 模拟器，点击 Run。无需安装第三方依赖。
3. 真机运行时，在 Signing & Capabilities 中选择自己的开发团队，并按需修改 Bundle Identifier（默认 `com.duoduo.checkin`）。签名配置以当前工程为准；不要为覆盖安装随意修改 Bundle Identifier，以免切换到新的数据容器。

家长密码固定为 **885802**。修改位置为 `Sources/DodoCore/TaskCatalog.swift` 中的 `AppRules.parentPassword`，改后重新编译安装。没有 Keychain、密码设置、修改或找回流程。

## 使用方式

- 今日打卡：单次任务直接打卡；三餐、作业、阅读需要先开始计时，再结束打卡。关闭 App、锁屏后计时继续按真实经过时间计算。
- 自动规则负责正常计分：儿童完成达标任务后积分立即生效，停止累计计时后新增分数立即生效，无达标立即计分。首页统一显示今日打卡分和奖励分。
- 默认 17 个项目，每日目标 **13 分**。项目与目标可配置，累计计时任务没有固定日分值上限；只有有效打卡分参与每日达标，奖励分不参与。
- 默认自然周达标 7 天奖励 **10 分**，自然月达标 25 天奖励 **50 分**。新版月奖励只有一档，周月奖励可以叠加。修改奖励配置后立即应用于当前周/月，已经发放的奖励保持原金额，不重复发放。
- 星际旅程按自然月更新：当月有效打卡分加当月发放的奖励分，默认每满 50 分解锁一颗星球，共八颗；可在设置中修改步长，保存后立即更新本月进度。新月份重新探索，历史积分和消费余额保留。
- 孩子不能自行重试超时三餐；家长可取消当天任意已打卡项目（包括已完成、未达标或计时中的项目），取消后孩子可以按原时间规则重新打卡。双次任务从新的开始时间重新计时，重新达标后立即获得积分。作业超时也保留直接由家长验证后重新计时的入口。尚无记录的阅读默认每满 15 分钟记 2 分，当天可以多次开始、停止并继续累积积分；暂停期间不计时。已得分数保留，新增积分自动生效。家长取消阅读后本轮累计清零，旧分段记录保留。当天已有的阅读记录继续沿用建立记录时的规则。
- 取消会移除该项打卡分和统计次数，并撤回当天已发放但不再满足条件的周期奖励；重新达标后可再次获得相应奖励，不会重复计分。取消三餐或作业时，若“做事不拖拉”启用了前置条件，其已完成记录也会取消并重新锁定。
- 取消前的打卡时间、计时尝试及家长取消时间会保留在记录中，旧版保存的数据可直接读取。
- 三餐及作业达标完成后解锁“做事不拖拉”。
- 所有时间采用北京时间。午夜封存记录，不能补打或更改历史；未结束的计时段不计入完成，累计任务已停止并结算的分数保留。

新增“认真听讲”：单次打卡、2 分、无时间限制，达标立即计分；本次升级当天起采用 17 项，之前的日期保留原统计项目数。

此前新增“干净卫生”“自己穿衣”：均为单次打卡、每项 1 分、无时间限制，达标立即计分。项目升级前日期保留 14 项统计口径，该次升级当天起采用 16 项；每日达标统一按 13 分有效分判定，旧打卡记录和已发放奖励保留。

家长管理提供“暂不处理 / 补打卡 / 取消打卡”，默认全部暂不处理。完全未打卡、未达标、暂停、计时中和已取消的当日项目都可以补打；输入密码 885802 后提交。已完成项目重复补打不加分。补打不会伪造实际完成时间：保留原尝试及失败原因，追加“家长补打”操作时间。

补打使用该项目当日记录快照的分值；无记录时使用当前配置。累计计时补打至少补记一个计分单位，正在运行的计时先停止并保留实际时长，得分取累计规则分与补记分中的较大值；后续继续计时仍取较大值，不把补记分再加一次。取消后本轮计时及补记分清零，旧尝试保留。

升级至自动计分时，全部已有达标记录（含历史待确认记录、累计计时尚未确认的新增分数）统一计入有效分；失败、未完成和已取消记录不计分。迁移保留原时间、原分数、旧家长审核记录及消费记录，仅补齐有效积分和统计；当前周/月奖励满足条件时结算，已封存周期不追补奖励。沿用原 SwiftData 数据容器，迁移幂等，重启不重复发放。

任务完整规则可在 App 左上角“计分规则”查看。

## 设置与生效时间

第四个 Tab 为“设置”，包含“打卡配置”和“奖励机制”。每次进入条目前验证固定家长密码，返回后台后关闭配置页，重新进入需要再次验证。

- **打卡配置**：编辑现有默认项目或新增项目；填写名称，从通用星星图标及原有 17 张图标中选择，选择四个分组之一，设置正整数分值。新增项目默认使用通用图标。项目名称不能重复。
- 每个项目默认勾选，点击左侧勾选即可立即控制首页显示；未勾选项目仍留在配置列表，方便恢复。左滑项目可删除配置。隐藏或删除均保留已有记录和积分，历史与家长管理仍可查看已有记录；空分区不再显示在首页。
- **时间区间**：起始时间默认 00:00，可修改，结束时间可选是否包含整点；支持休息日不同结束时间，时间区间限同一天内。起床默认保留工作日/休息日规则及法定节假日判断。
- **计时 >n 分钟**：按 `floor(累计秒数 / (n × 60)) × 分值` 计分，例如每 15 分钟 2 分，累计 35 分钟得 4 分。不足一个周期的时间留在当天累计中，可继续开始/停止，新增分数立即生效，统计次数每天仍只算一次。
- **计时 =n 分钟**：按完整分钟判断，例如 =30 分钟可在 30:00～30:59 结束。
- **计时 <n 分钟**：严格小于指定时长；可打开“包含上限整点”成为 ≤。默认三餐和作业保留原来的 ≤30 / ≤60 分钟规则。
- **无规则**：单次完成；默认“做事不拖拉”额外保留三餐和作业达标前置条件，可在其配置中关闭。
- **奖励机制**：日目标、周达标天数/分数、月达标天数/分数及月度星球步长。周、月天数均为累计，不要求连续。月天数若高于实际月份长度，按全月达标，例如设 31 天时二月按当月 28 或 29 天。

所有新增和修改的配置均在**保存成功后立即生效**。新增项目立即出现在今日打卡中；当天尚无记录的项目立即采用新配置。当天已有记录的项目（包括计时中、暂停、完成、未达标或取消）继续沿用原项目快照，次日新记录采用新配置。日目标、周/月奖励条件及星球步长立即更新；历史日期的目标、任务、积分不变。默认日目标仍为 13 分。

修改奖励条件时，只用有效打卡积分检查是否达到新的奖励条件，满足则在同一次保存中发放。已发放奖励保留原分数、标题和发放条件，不因提高门槛或修改分数被撤回、重算或重复发放；家长主动取消打卡时仍按该奖励原发放条件判断是否应撤回。

兼容旧版待生效配置：编辑器保留之前保存的值，再次保存该类配置时立即应用，并替换该类尚未生效的版本，避免到旧预定日期后又被覆盖。

配置按日期保存版本，打卡记录保存项目名称、图标、分组、规则及分值快照，奖励保存实际发放分数。历史记录不重新计分。沿用原 SwiftData 数据容器和文档，兼容旧数据，没有清空或重建数据库的升级流程。

## 积分消耗

第三个 Tab 展示累计总分、已消耗积分和剩余积分。累计总分包含所有有效打卡分及奖励分；消耗单独记账，不改变今日打卡、打卡统计、每日达标或星球解锁进度。

- 看动画片：点击开始记录实际时间，点击结束生成一条消耗记录；每天可以多次观看。每次仅按完整的 2 分钟消耗 1 分，例如 5 分钟扣 2 分，不足 2 分钟的尾数不跨次累计。零积分的短时观看也保留记录。
- 允许负余额：手动消耗可超过余额；零分或负分时也可开始观看，不因积分用完自动结束。观看中已产生的消耗实时计入余额，后续得分抵扣缺口。
- 手动消耗：填写 1 至 40 个字的项目名称及正整数积分，提交后记录当前日期、时间、名称和积分。观看期间也可以手动记账，不改变当前观看计时。
- 观看起点持久化保存，锁屏、切后台、重启或跨午夜后按实际经过时间恢复；计时持续到用户点击结束，按完整的 2 分钟扣分。本功能记录观看时间，不控制其他视频 App 的播放。
- 下方按结束时间倒序展示消耗记录；动画片额外展示开始时间和观看时长（旧版自动结束记录仍保留原标记），均采用北京时间。

家长撤回打卡时，仍按原规则撤回有效分及相关奖励，已发生的消耗保留。若因此产生积分缺口，页面显示实际负余额，仍可继续记录消费，之后得分抵扣缺口。

## 统计口径

次数、打卡率、排行榜统计自动达标和家长补打的有效任务。双次打卡算一个任务，作业重试不增加次数。有效打卡分和奖励分单独展示，合计积分为两者之和。

打卡率的分母为统计周期与“首次启动日至今天”交集内每天应打卡项目数之和（当日启用项目与当日已有记录项目的并集），包括没有打开 App 的日期。隐藏、删除不移除已有记录，历史日期保留当日配置。前三项同次数时按任务固定顺序排列，不展示零次项目。

周/月奖励要求实际达标，首次启用之前的日期不算达标。达到当前周期配置的天数后，打卡或家长补打时立即结算，每个周期一次。奖励归属实际发放日及该日所在周/月。月奖励按当前配置的一档执行；旧版已经发放的两档奖励仍按原金额保留。

## 工程结构

- `App/`：今日打卡、打卡统计、积分消耗、设置四个主页面，家长密码页、历史详情、规则、星际旅程和庆祝效果。
- `Sources/DodoCore/`：任务定义、北京时间日历、打卡状态机、奖励、统计、积分消耗账本、节假日校验、SwiftData 存储。
- `Tests/DodoCoreTests/`：可在 macOS 独立运行的规则及持久化测试。
- `UITests/`：模拟器端到端打卡、密码错误/正确验证、统计、规则及只读历史测试。
- `Artwork/`：ImageGen 素材预览、完整提示词及文件校验清单。
- `tools/`：工程生成脚本、图片透明度验证及旧版图标绘制脚本。

App 和 Swift Package 共用核心源文件，没有外部 Swift 包依赖。Swift 6 模式、完整并发检查；UI 状态和 SwiftData Context 在主执行器上使用，纯规则为可传递的值类型。

SwiftData 保存单个版本化 Journal 文档，其中包含每日任务、所有计时尝试、家长审核记录、奖励、首次启用日期，以及消耗记录、正在进行的观看和按日期生效的配置版本。旧版本没有消耗字段时自动视为空账本，保留原有积分。一次打卡、补打或取消及其奖励变化编码为同一份快照后统一保存，失败则回滚，不显示成功反馈。读取失败会显示错误和重试入口，不会静默清空历史。

## 节假日日历

内置 `Sources/DodoCore/Resources/2026.json`，来自 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn)，已按[国务院 2026 年安排的政府网站转载](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)核对放假及补班日。原始来源见 JSON 的 `papers`，MIT 许可证随数据保留。

启动、返回前台及跨年时按需读取当前和下一年的公共 HTTPS 数据（6 小时内不重复请求），校验年份、日期、重复项及公告来源后缓存。节假日覆盖普通星期规则，缺少年度数据时首页提示暂按周末判定。断网可使用内置/缓存数据；当前打卡的规则判定会保存为快照，后续更新不追溯改写。网络请求不包含儿童打卡记录或密码。

## 开发命令

```sh
# 核心规则及 SwiftData 测试
swift test

# 工程生成脚本会重写工程设置；已有签名等自定义配置时优先在 Xcode 中增删文件
python3 tools/generate_project.py

# 验证当前 ImageGen 图片尺寸和真实透明通道
swift tools/verify_artwork.swift

# 编译模拟器版本
xcodebuild -project DodoCheckIn.xcodeproj -scheme DodoCheckIn \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO build

# UI 测试（设备名替换为本机可用模拟器）
xcodebuild -project DodoCheckIn.xcodeproj -scheme DodoCheckIn \
  -destination 'platform=iOS Simulator,name=iPhone 17e' \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO test
```

UI 测试仅在 Debug 编译下使用 `--uitesting` 参数启用内存数据库，避免写入日常记录；没有修改系统时间、加速计时或绕过家长密码的测试入口。

验证详情见 `docs/VALIDATION.md`。

## 视觉素材

首页按第二版 iPhone 设计稿实现：熊猫与飞船出发场景、17 张独立任务插画、月度星球轨道预览。四组任务统一双列，奇数项的最后一张保持半宽。导航栏使用 `NavigationStack` 和原生工具栏，底部使用原生 `TabView`；文字、进度和按钮均由 SwiftUI 实时渲染。

ImageGen 素材共 40 张（包含保留的旧背景），包含首页场景、17 张透明任务插画及四组透明基地边框。查看 [素材说明](Artwork/README.md)、[素材画廊](Artwork/index.html) 及 [本轮生成提示词](Artwork/home-native-assets-prompts.json)。

任务卡显示名称、独立插画、星星分值、简短时间说明和操作按钮：三餐显示“30分钟”，保留计时器图标；计时中仅显示“25:11”，结束后显示“25:11/30”，阅读运行时显示本轮累计时间，暂停或完成后显示累计时长和当前配置的目标；洗漱和睡觉显示“晚上9:00”“晚上9:30”。完整规则与精确起止时间仍可在规则和历史中查看。

分区背景、卡片底色与边框都使用各自主题色；达标后加深主题色边框，直接显示无按钮底色的主题色图标和“已完成”文字；累计计时可继续。去掉待确认状态与审核印章，家长补打的任务显示“家长补打”。任务插画完整适配，不裁切；旧版整张任务背景已保留但不再用于首页。顶部显示今日打卡分和奖励分，每日目标只使用有效分；月度星球按当前月份的配置步长解锁，默认 50 分。

四个分区按固定顺序展示，区域底色、按钮和未完成边框使用对应主题色：

- 能量补给站（`#FF8D28`）：起床、吃早饭、吃午饭、吃晚饭、睡觉。
